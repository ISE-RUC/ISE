# 党团模块学生端使用手册

本文档面向学生账号，用于说明学生端的页面入口、材料提交、审批提交、提醒查看和历史记录查看方式。

## 1. 启动与登录

推荐使用测试库启动：

```bash
pip install -r requirements.txt
python manage.py migrate --settings=config.settings_testdb
python manage.py seed_party_data --with-demo-users --settings=config.settings_testdb
python manage.py runserver --settings=config.settings_testdb
```

访问：

`http://127.0.0.1:8000/`

演示账号：

- 入党流程学生：`party_student / party1234`
- 入团流程学生：`league_student / party1234`

## 2. 学生端页面

登录后常用页面：

- 学生端首页：`/party/student/`
- 时间轴：`/party/student/timeline/`
- 材料提交：`/party/student/materials/`
- 办理历史：`/party/student/history/`

说明：

- `party_student` 用于体验入党流程
- `league_student` 用于体验入团流程

## 3. 首页查看内容

页面：`/party/student/`

当前可以查看：

- 当前阶段
- 当前节点
- 预计下一节点日期
- 当前状态
- 当前待办材料
- 提醒事项

建议检查：

1. 当前阶段是否正确
2. 当前节点是否正确
3. 提醒事项是否展示

## 4. 时间轴查看

页面：`/party/student/timeline/`

当前可以查看：

- 全部标准节点
- 当前节点高亮
- 已完成节点
- 待进入节点

## 5. 材料提交与审批提交

页面：`/party/student/materials/`

当前可以执行：

- 查看当前节点所需材料
- 上传材料文件
- 查看已上传版本
- 在材料齐备后提交审批

建议操作顺序：

1. 打开材料页
2. 对照当前节点要求上传材料
3. 确认材料状态变为已上传
4. 点击“提交审批”
5. 返回首页确认状态变化

## 6. 提醒事项

提醒会展示在学生首页。

当前可能看到的提醒类型：

- 材料准备提醒
- 节点可推进提醒
- 审批待办提醒
- 逾期提醒

如果管理员执行了提醒命令：

```bash
python manage.py generate_party_reminders --settings=config.settings_testdb
python manage.py send_party_reminders --settings=config.settings_testdb
```

学生首页会看到更完整的提醒状态。

## 7. 办理历史

页面：`/party/student/history/`

当前可以查看：

- 每个节点的材料版本
- 审批任务
- 审批动作
- 驳回意见
- 撤回链路
- 撤回后状态

如果某次审批结果被撤回，历史页会明确展示：

- 原审批结果已撤回
- 撤回时间
- 撤回人
- 撤回说明
- 撤回后状态：该节点已重新打开审核，当前回到待审批

## 8. 学生端自测建议

建议按以下顺序检查：

1. 登录学生账号
2. 查看首页当前阶段和提醒事项
3. 进入时间轴页确认当前节点高亮
4. 进入材料页上传材料
5. 提交审批
6. 让管理老师完成一次驳回或通过
7. 返回历史页检查审批链路
8. 如管理老师做了撤回，再检查历史页中的撤回链路文案

## 9. 常见问题

### 9.1 看不到党团档案

说明当前账号还没有建立党团档案。验收建议直接使用：

- `party_student / party1234`
- `league_student / party1234`

### 9.2 材料上传后不能提交审批

通常是因为当前节点仍有必需材料未提交，或者节点状态不允许重复提交审批。

### 9.3 历史页看不到审批链路

说明当前节点还未形成审批任务，先完成一次“提交审批”后再查看。
