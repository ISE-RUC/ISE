# 党团模块测试库启动与验收清单

本文档用于你现在按步骤做一遍人工检测。

## 1. 测试库启动

在仓库根目录执行：

```bash
pip install -r requirements.txt
python manage.py migrate --settings=config.settings_testdb
python manage.py seed_party_data --with-demo-users --settings=config.settings_testdb
python manage.py runserver --settings=config.settings_testdb
```

访问：

`http://127.0.0.1:8000/`

## 2. 演示账号

- 管理老师：`party_admin / party1234`
- 入党流程学生：`party_student / party1234`
- 入团流程学生：`league_student / party1234`

## 3. 管理端验收清单

### 3.1 流程规则页

页面：`/party/admin/rules/`

检查项：

- 能看到流程类型切换
- 能看到节点定义列表
- 能新增或编辑节点定义
- 能新增或编辑材料类型
- 能新增或编辑节点材料要求

### 3.2 成员列表

页面：`/party/admin/members/`

检查项：

- 关键词筛选生效
- 年级筛选生效
- 专业关键词筛选生效
- 排序生效
- 分页生效

### 3.3 审批工作台

页面：`/party/admin/approvals/`

检查项：

- 关键词筛选生效
- 当前阶段筛选生效
- 待审批列表分页生效
- 可撤回结果分页生效
- 选中任务后右侧显示材料和审批链路
- 勾选当前页多条待审批任务后可执行批量通过
- 批量驳回时不填写原因不能提交
- 批量处理后仍保持当前筛选上下文返回

### 3.4 撤回规则

检查项：

- 撤回说明留空时不能提交
- 已处理结果可在时效内撤回
- 撤回后链路里能看到撤回人和撤回说明
- 撤回后状态显示为“已重新打开审核，当前节点回到待审批”

### 3.5 批量导入导出

页面：`/party/admin/import/`

检查项：

- 能下载导入模板
- 上传模板后先出现预校验结果
- 点击“确认导入写库”后才真正写入
- 错误模板能生成错误清单
- 能导出成员流程状态总表
- 能导出审批记录明细

## 4. 学生端验收清单

### 4.1 首页

页面：`/party/student/`

检查项：

- 当前阶段显示正确
- 当前节点显示正确
- 提醒事项模块显示正常

### 4.2 时间轴

页面：`/party/student/timeline/`

检查项：

- 当前节点高亮
- 已完成节点和待进入节点显示正常

### 4.3 材料页

页面：`/party/student/materials/`

检查项：

- 能上传材料
- 上传后能看到版本号
- 材料齐备后能提交审批

### 4.4 历史页

页面：`/party/student/history/`

检查项：

- 能看到材料版本
- 能看到审批链路
- 驳回意见显示正常
- 撤回链路显示正常
- 撤回后状态文案显示正常

## 5. 推荐验收顺序

1. 管理老师登录，先看流程规则页
2. 用 `party_student` 体验一轮入党流程：上传材料并提交审批
3. 管理老师进入审批工作台处理一次单条审批
4. 用 `league_student` 再体验一轮入团流程
5. 管理老师再执行一次批量审批
6. 管理老师执行一次撤回
7. 学生查看历史页
8. 管理老师做一次导入预校验和确认导入
9. 管理老师导出成员状态和审批记录

## 6. 自动化验证

如果你希望在人工检查前先确认自动化测试通过，可执行：

```bash
python manage.py test apps.party.tests --settings=config.settings_testdb
```

当前 `party` 模块相关测试应全部通过。
