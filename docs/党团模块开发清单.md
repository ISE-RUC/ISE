# 党团模块开发清单

本文档用于记录 `apps/party` 模块当前已经完成的工作，以及后续仍待推进的事项，便于组内同步开发进度。

## 一、当前阶段结论

`party` 模块的“最小可运行闭环”已经完成。

当前已经可以跑通以下主链路：

1. 学生查看当前党团进度
2. 学生查看流程时间轴
3. 学生上传当前节点材料
4. 学生提交当前节点审批
5. 管理老师查看待审批任务
6. 管理老师通过或驳回审批
7. 管理老师批量通过或批量驳回待审批任务
8. 管理老师在时效内撤回审批结果
9. 学生和老师查看材料与审批历史

## 三、当前可直接演示的功能

演示账号：

- 管理老师：`party_admin / party1234`
- 入党流程学生：`party_student / party1234`
- 入团流程学生：`league_student / party1234`

当前可演示流程：

1. 学生登录后进入 `party/student/materials/`

3. 提交审批
4. 管理老师进入 `party/admin/approvals/`
5. 对任务执行通过或驳回
6. 必要时执行撤回
7. 学生和老师分别查看历史链路变化
