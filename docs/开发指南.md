# 开发指南

## 快速开始

### 1. 环境准备

确保已安装 Python 3.8+，然后安装 Django：

```bash
pip install django
```

### 2. 启动项目

```bash
python manage.py runserver
```

访问 http://127.0.0.1:8000/ 查看主页。

## 各目录详细说明

### apps/ - 应用模块

每个子目录是一个独立的 Django app，包含：

- `models.py` - 数据模型（目前为空，后端开发时使用）
- `views.py` - 视图函数/类，处理请求并返回响应
- `urls.py` - 该模块的路由配置
- `admin.py` - Django 管理后台配置
- `apps.py` - 应用配置

**如何添加新功能：**

1. 在对应模块的 `views.py` 中添加视图类
2. 在 `urls.py` 中添加路由
3. 在 `templates/模块名/` 下创建对应的 HTML 模板

### templates/ - 模板文件

使用 Django 模板语言编写的 HTML 文件。

**模板继承：**

所有页面都应继承 `base.html`：

```html
{% extends "base.html" %}
{% block title %}页面标题{% endblock %}
{% block content %}
    <!-- 页面内容 -->
{% endblock %}
```

**URL 引用：**

使用 `{% url %}` 标签引用路由：

```html
<a href="{% url 'qa:index' %}">智能问答</a>
```

### static/ - 静态资源

存放 CSS、JavaScript、图片等静态文件。

**在模板中引用静态文件：**

```html
{% load static %}
<link rel="stylesheet" href="{% static 'css/main.css' %}">
<img src="{% static 'img/logo.png' %}" alt="Logo">
```

### config/ - 项目配置

- `settings.py` - 包含所有项目配置（数据库、中间件、应用列表等）
- `urls.py` - 全局路由，将不同路径分发到各个 app

## 开发流程

### 添加新页面

以"智能问答"模块为例：

1. **编辑视图** (`apps/qa/views.py`)：

```python
from django.views.generic import TemplateView

class QuestionView(TemplateView):
    template_name = 'qa/question.html'
```

2. **添加路由** (`apps/qa/urls.py`)：

```python
from django.urls import path
from . import views

app_name = 'qa'

urlpatterns = [
    path('', views.IndexView.as_view(), name='index'),
    path('question/', views.QuestionView.as_view(), name='question'),
]
```

3. **创建模板** (`templates/qa/question.html`)：

```html
{% extends "base.html" %}
{% block title %}提问{% endblock %}
{% block content %}
<div class="card">
    <h1>智能问答</h1>
    <!-- 页面内容 -->
</div>
{% endblock %}
```

### 修改样式

编辑 `static/css/main.css`，使用 CSS 变量保持风格统一：

```css
:root {
    --primary: #A6192E;      /* 主题色 */
    --primary-soft: #f8e9ec; /* 主题色浅色版 */
    --bg: #f5f6f8;           /* 背景色 */
    --card: #ffffff;         /* 卡片背景 */
    --text: #1f2937;         /* 文字颜色 */
    --muted: #6b7280;        /* 次要文字 */
}
```

## 代码规范

### Python 代码规范

1. **命名规范**
   - 类名使用大驼峰：`class UserProfile`
   - 函数/变量使用小写下划线：`def get_user_info()`
   - 常量使用大写下划线：`MAX_UPLOAD_SIZE`

2. **导入顺序**
   ```python
   # 标准库
   import os
   import sys

   # Django 相关
   from django.views.generic import TemplateView
   from django.shortcuts import render

   # 第三方库
   import requests

   # 本地模块
   from .models import User
   ```

3. **视图类规范**
   ```python
   class IndexView(TemplateView):
       """首页视图 - 简短的类说明"""
       template_name = 'app/index.html'

       def get_context_data(self, **kwargs):
           context = super().get_context_data(**kwargs)
           # 添加上下文数据
           return context
   ```

### HTML/模板规范

1. **缩进**：使用 4 个空格
2. **模板标签**：`{% %}` 和 `{{ }}` 内外各留一个空格
3. **注释**：使用 `{# 注释内容 #}` 或 HTML 注释 `<!-- -->`

```html
{% extends "base.html" %}

{% block content %}
<div class="card">
    {# 这是模板注释 #}
    <h1>{{ title }}</h1>
    {% for item in items %}
        <p>{{ item.name }}</p>
    {% endfor %}
</div>
{% endblock %}
```

### CSS 规范

1. **使用 CSS 变量**：优先使用 `:root` 中定义的变量
2. **类名规范**：使用小写字母和连字符，语义化命名
3. **避免深层嵌套**：尽量保持选择器简洁

```css
/* 推荐 */
.card-header {
    background: var(--primary);
    padding: 16px;
}

/* 不推荐 */
.card .header .title .text {
    color: #A6192E;
}
```

## 常见问题

### 修改后页面没变化？

1. 刷新浏览器（Ctrl+F5 强制刷新）
2. 检查是否修改了正确的文件
3. 确认 Django 开发服务器正在运行

### 找不到模板？

检查 `config/settings.py` 中的 `TEMPLATES` 配置：

```python
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [BASE_DIR / 'templates'],  # 确保这行存在
        'APP_DIRS': True,
        ...
    },
]
```

### 静态文件加载失败？

1. 确认文件路径正确
2. 检查模板中是否使用了 `{% load static %}`
3. 确认 `settings.py` 中的 `STATICFILES_DIRS` 配置正确
