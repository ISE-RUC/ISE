# 前端样式指南

## 设计风格

本项目采用**严谨、正式、朴素的校园政务风格**，主要特点：

- 主题色：中国红 `#A6192E`
- 圆角设计：大圆角（16-28px）营造柔和感
- 卡片布局：使用白色卡片承载内容
- 阴影效果：轻微阴影增加层次感

## 颜色系统

### CSS 变量

所有颜色都定义在 `static/css/main.css` 的 `:root` 中：

```css
:root {
    --primary: #A6192E;          /* 主题色（中国红） */
    --primary-soft: #f8e9ec;     /* 主题色浅色版 */
    --bg: #f5f6f8;               /* 页面背景色 */
    --card: #ffffff;             /* 卡片背景 */
    --text: #1f2937;             /* 主要文字 */
    --muted: #6b7280;            /* 次要文字 */
    --line: #e5e7eb;             /* 分割线 */
    --soft: #f8fafc;             /* 柔和背景 */
    --warning-bg: #fff7ed;       /* 警告背景 */
    --warning: #b45309;          /* 警告文字 */
    --success-bg: #ecfdf5;       /* 成功背景 */
    --success: #047857;          /* 成功文字 */
    --shadow: 0 10px 30px rgba(15,23,42,.06);  /* 阴影 */
    --radius: 20px;              /* 圆角 */
}
```

### 使用示例

```css
.my-button {
    background: var(--primary);
    color: #fff;
    border-radius: var(--radius);
    box-shadow: var(--shadow);
}
```

## 常用组件

### 1. 卡片 (Card)

```html
<div class="card">
    <h2>卡片标题</h2>
    <p>卡片内容</p>
</div>
```

### 2. 按钮 (Button)

```html
<!-- 主要按钮 -->
<button class="btn btn-primary">确认</button>

<!-- 普通按钮 -->
<button class="btn">取消</button>
```

### 3. 标签 (Pill)

```html
<span class="pill pill-primary">重要</span>
<span class="pill pill-warning">待处理</span>
<span class="pill pill-success">已完成</span>
```

### 4. 输入框

```html
<input type="text" placeholder="请输入内容" style="
    height: 48px;
    border: 1px solid var(--line);
    border-radius: 16px;
    padding: 0 16px;
    background: #fff;
    outline: none;
">
```

### 5. 网格布局

```html
<!-- 两栏布局 -->
<div class="grid-main">
    <div class="card">左侧内容</div>
    <div class="card">右侧内容</div>
</div>

<!-- 三栏网格 -->
<div class="action-grid">
    <div class="action-item">项目1</div>
    <div class="action-item">项目2</div>
    <div class="action-item">项目3</div>
</div>
```

## 响应式设计

项目已内置响应式断点：

- **桌面端**：> 1080px（默认样式）
- **平板端**：720px - 1080px（两栏变单栏）
- **移动端**：< 720px（单栏布局，隐藏部分元素）

### 示例

```css
/* 桌面端 */
.grid-main {
    grid-template-columns: 1.55fr 1fr;
}

/* 平板端 */
@media (max-width: 1080px) {
    .grid-main {
        grid-template-columns: 1fr;
    }
}

/* 移动端 */
@media (max-width: 720px) {
    .card {
        padding: 18px;
    }
}
```

## 间距规范

使用 4 的倍数作为间距单位：

- `4px` - 极小间距
- `8px` - 小间距
- `12px` - 常规间距
- `16px` - 中等间距
- `24px` - 大间距
- `32px` - 超大间距

```css
.example {
    padding: 16px;        /* 内边距 */
    margin-bottom: 24px;  /* 外边距 */
    gap: 12px;           /* Flexbox/Grid 间距 */
}
```

## 字体规范

### 字号

- `34px` - 主标题
- `24px` - 品牌标题
- `22px` - 卡片标题
- `19px` - 子标题
- `14px` - 正文
- `12px` - 辅助文字

### 字重

- `700` - 粗体（标题）
- `600` - 半粗（按钮）
- `500` - 中等
- `400` - 常规（正文）

```css
.title {
    font-size: 22px;
    font-weight: 700;
}

.description {
    font-size: 14px;
    font-weight: 400;
    color: var(--muted);
}
```


## 最佳实践

### 1. 保持一致性

- 使用 CSS 变量而非硬编码颜色
- 遵循统一的圆角、间距规范
- 保持组件样式的一致性

### 2. 语义化 HTML

```html
<!-- 推荐 -->
<header>...</header>
<main>...</main>
<section>...</section>
<article>...</article>

<!-- 不推荐 -->
<div class="header">...</div>
<div class="main">...</div>
```

### 3. 避免内联样式

```html
<!-- 不推荐 -->
<div style="color: red; padding: 10px;">内容</div>

<!-- 推荐 -->
<div class="alert">内容</div>
```

```css
.alert {
    color: var(--warning);
    padding: 10px;
}
```

### 4. 移动优先

考虑移动端体验，确保在小屏幕上也能正常使用。

## 调试技巧

### 1. 浏览器开发者工具

- `F12` 打开开发者工具
- 使用"元素"面板查看和修改样式
- 使用"响应式设计模式"测试不同屏幕尺寸

### 2. CSS 边框调试

临时添加边框查看布局：

```css
* {
    border: 1px solid red !important;
}
```

### 3. 检查 CSS 变量

在开发者工具的"计算"面板中查看 CSS 变量的实际值。
