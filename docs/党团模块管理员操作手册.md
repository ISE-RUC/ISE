# 党团模块管理员操作手册

本文档面向管理老师，用于指导在测试库环境下完成党团模块的日常操作、验收检查和问题定位。

## 1. 使用前准备

### 1.1 推荐启动方式

优先使用测试库配置启动：

```bash
pip install -r requirements.txt
python manage.py migrate --settings=config.settings_testdb
python manage.py seed_party_data --with-demo-users --settings=config.settings_testdb
python manage.py runserver --settings=config.settings_testdb
```

访问：

`http://127.0.0.1:8000/`

### 1.2 演示账号

- 管理老师：`party_admin / party1234`
- 入党流程学生：`party_student / party1234`
- 入团流程学生：`league_student / party1234`

## 2. 管理端入口

登录管理老师账号后，进入：

- 管理端首页：`/party/admin/`
- 成员列表：`/party/admin/members/`
- 审批工作台：`/party/admin/approvals/`
- 流程规则配置：`/party/admin/rules/`
- 批量导入导出：`/party/admin/import/`

## 3. 常用操作

### 3.1 查看成员列表

页面：`/party/admin/members/`

当前支持：

- 关键词筛选：姓名、学号、专业、年级
- 年级筛选
- 专业关键词筛选
- 当前阶段筛选
- 审批状态筛选
- 排序
- 分页

建议验收动作：

1. 用关键词搜索 `party_student`
2. 再用关键词搜索 `league_student`
3. 按“当前阶段”筛选 `申请人`
4. 按“待审批任务多到少”排序
5. 进入任一成员详情页

### 3.2 查看成员详情

页面：`/party/admin/members/<id>/`

当前支持：

- 查看学生基础信息
- 查看流程时间轴
- 查看节点材料版本
- 查看审批链路
- 查看撤回链路和撤回后状态
- 跳转到该学生的审批任务

建议验收动作：

1. 打开成员详情
2. 核对当前阶段与当前节点
3. 查看“节点材料与审批链路”
4. 确认撤回后的文案显示为“撤回后状态：已重新打开审核，当前节点回到待审批”

### 3.3 审批工作台

页面：`/party/admin/approvals/`

当前支持：

- 查看待审批任务
- 查看可撤回结果
- 按关键词筛选
- 按当前阶段筛选
- 排序
- 待审批列表分页
- 可撤回结果分页
- 查看节点材料
- 审批通过
- 审批驳回
- 撤回审批结果

建议验收动作：

1. 先用学生账号提交审批
2. 管理老师进入审批工作台
3. 选中待审批任务
4. 查看“材料核对”
5. 执行“通过”或“驳回”
6. 如需验证撤回，再到“可撤回结果”中选中已处理任务

### 3.4 撤回规则

撤回时当前已生效的规则：

- 仅原审批人或学院领导可撤回
- 撤回说明必填
- 超过撤回时效不能撤回
- 当前节点已存在新的待审批任务时不能重复撤回
- 驳回后若学生已补交新材料，不能再撤回原驳回结果

建议验收动作：

1. 对同一任务先执行一次通过或驳回
2. 在撤回表单中留空说明，确认系统阻止提交
3. 填写说明后撤回，确认链路中出现：
   - 撤回人
   - 撤回说明
   - “撤回后状态：已重新打开审核，当前节点回到待审批”

### 3.5 流程规则配置

页面：`/party/admin/rules/`

当前支持：

- 流程类型切换
- 节点定义新增/编辑/启停
- 材料类型新增/编辑/启停
- 节点材料要求新增/编辑
- 必需/选填切换

建议验收动作：

1. 新建一个节点定义
2. 新建一个材料类型
3. 给某个节点增加材料要求
4. 再打开学生端材料页确认要求变化

### 3.6 批量导入导出

页面：`/party/admin/import/`

当前支持：

- 下载导入模板
- Excel 预校验
- 确认导入写库
- 取消本次预览
- 下载导入错误清单
- 导出成员流程状态总表
- 导出审批记录明细

#### 导入建议流程

1. 点击“下载模板”
2. 按模板填写学生当前状态
3. 上传文件并先做预校验
4. 核对预览中的：
   - 将新增/更新哪些学生
   - 将新增/更新哪些党团档案
   - 历史完成节点
   - 当前节点与节点状态
5. 点击“确认导入写库”

#### 导入模板关键字段

- `username`：学生账号，必填
- `student_id`：学号，建议填写
- `track_type`：流程类型，如 `party` 或 `league`
- `current_stage`：当前阶段，如 `applicant`
- `completed_stage_definition_codes`：历史已完成节点编码，英文逗号分隔，如 `party_applicant,party_activist` 或 `league_applicant,league_activist`
- `current_stage_definition_code`：当前节点编码，如 `party_applicant` 或 `league_applicant`
- `current_stage_status`：当前节点状态，如 `open`、`submitted`

#### 错误清单说明

当预校验失败时，页面会保留“最近一次导入错误”，并允许下载错误清单 Excel。建议先修正错误清单，再重新导入，不要绕过预校验。

## 4. 提醒机制

当前提醒能力已接入。

命令：

```bash
python manage.py generate_party_reminders --settings=config.settings_testdb
python manage.py send_party_reminders --settings=config.settings_testdb
```

用途：

- `generate_party_reminders`：同步提醒任务
- `send_party_reminders`：将到期站内提醒标记为已发送

建议验收动作：

1. 先生成提醒
2. 用学生账号登录首页
3. 查看“提醒事项”模块

## 5. 一次完整验收建议

建议按以下顺序走一遍：

1. 用测试库启动系统
2. 管理老师登录并打开流程规则页
3. 确认节点、材料、节点材料要求可查看和修改
4. 学生登录并上传材料、提交审批
5. 管理老师在审批工作台处理审批
6. 管理老师执行一次撤回并检查撤回链路
7. 管理老师打开批量导入导出页，下载模板并完成一次预校验
8. 管理老师导出成员流程状态总表和审批记录明细
9. 学生查看历史页与首页提醒

## 6. 常见问题

### 6.1 页面打不开或数据异常

优先确认是否使用了测试库配置启动：

```bash
python manage.py runserver --settings=config.settings_testdb
```

### 6.2 默认库出现迁移不一致

当前验收不要直接依赖默认 `db.sqlite3`，优先使用 `config.settings_testdb`。

### 6.3 导入没有真正写入

当前导入采用“两步走”：

1. 预校验
2. 确认导入写库

如果只做了预校验，没有点击“确认导入写库”，数据库不会变更。
